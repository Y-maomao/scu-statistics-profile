统计学基础与机器学习笔记

整理时间：2019年11月 · 分类：学习笔记

本文整理了统计学基础概念与机器学习实践中常用方法的笔记，主要供个人复习和同行交流使用。

一、概率论基础

概率论是统计学的数学基础，也是理解机器学习算法的关键。以下几个概念在面试和实践中反复出现。

贝叶斯定理

贝叶斯定理描述了在观察到新证据后如何更新先验信念。公式：P(A|B) = P(B|A) * P(A) / P(B)。在机器学习中，贝叶斯定理是朴素贝叶斯分类器、贝叶斯线性回归、变分推断等方法的理论基础。理解贝叶斯定理的关键是区分先验、似然和后验三个概念。

大数定律与中心极限定理

大数定律说明样本均值随样本量增大趋近于总体期望。中心极限定理说明无论总体分布如何，样本均值的分布在样本量足够大时趋近于正态分布。这两个定理是假设检验和置信区间构造的理论基础。

常见概率分布

正态分布：最重要的连续分布，自然现象中广泛存在。均值μ决定位置，标准差σ决定形状。 伯努利分布：最简单的离散分布，只有0和1两种结果。逻辑回归的输出就是伯努利分布的参数p。 泊松分布：描述单位时间内事件发生次数的离散分布，常用于稀有事件建模。 指数分布：描述事件间隔时间的连续分布，与泊松过程相关。

二、假设检验

假设检验是统计推断的核心工具，在A/B测试中直接使用。

基本流程

1. 设定原假设H0（通常是"没有差异"）和备择假设H1（"有差异"） 2. 选择检验统计量（t检验、卡方检验、F检验等） 3. 计算p值——在H0为真的条件下观察到当前或更极端结果的概率 4. 如果p值小于显著性水平（通常0.05），拒绝H0

常见错误

第一类错误（假阳性）：H0为真但拒绝了H0，概率为α。在A/B测试中就是"没有效果却认为有效果"。 第二类错误（假阴性）：H1为真但没有拒绝H0，概率为β。在A/B测试中就是"有效果但没检测到"。 统计功效（1-β）：正确拒绝H0的概率。A/B测试中通常要求功效≥0.8。

p值的陷阱

p值被广泛误用。p值小不代表效应量大，只代表证据反对原假设。多次检验时p值需要做Bonferroni校正，否则假阳性率会膨胀。在实际项目中，不能只看p值，还要看效应量、置信区间和实际业务意义。

三、回归分析

回归分析是统计学中最常用的方法之一，也是机器学习的基础。

线性回归

简单线性回归：y = β0 + β1*x + ε。最小二乘法通过最小化残差平方和来估计β0和β1。R²衡量模型解释的变异比例，取值0-1。

多元线性回归：y = β0 + β1*x1 + ... + βp*xp + ε。需要注意多重共线性——如果自变量之间高度相关，系数估计会不稳定。可以用VIF（方差膨胀因子）检测，VIF>10通常认为存在严重共线性。

逻辑回归

逻辑回归用于二分类问题，输出是概率值。模型形式：log(p/(1-p)) = β0 + β1*x1 + ... + βp*xp。最大似然估计求解系数。逻辑回归在金融风控、医疗诊断等可解释性要求高的场景中仍是主力模型。

正则化

Lasso（L1正则化）：在损失函数中加入系数绝对值之和的惩罚项，可以使部分系数收缩为0，起到特征选择作用。 Ridge（L2正则化）：加入系数平方和的惩罚项，收缩系数但不归零，适合存在共线性的场景。 ElasticNet：L1和L2的混合，兼顾特征选择和共线性处理。

四、特征工程实践

数值型特征处理

标准化（Z-score）：(x - mean) / std，使特征均值为0、标准差为1。适合大多数机器学习算法。 归一化（Min-Max）：(x - min) / (max - min)，缩放到[0,1]区间。适合神经网络。 对数变换：对右偏分布的数据取log，使其更接近正态分布。金融数据（收入、金额）经常需要。

类别型特征处理

One-Hot编码：低基数类别（<10个值）首选。简单直接但高基数时维度爆炸。 目标编码：高基数类别首选。用目标变量均值替代类别值。注意防泄露和低频平滑。 频数编码：用类别出现频次替代类别值，简单但对低频类别不友好。

时间特征提取

从时间戳中提取：年、月、日、星期、是否周末、是否节假日、小时、是否高峰时段。这些特征在零售预测和交通流量预测中非常有用。

五、模型评估

分类模型

混淆矩阵：TP（真阳性）、FP（假阳性）、TN（真阴性）、FN（假阴性）。 准确率：(TP+TN)/(TP+FP+TN+FN)。在不平衡数据上是误导性指标。 精确率：TP/(TP+FP)，预测为正的样本中实际为正的比例。 召回率：TP/(TP+FN)，实际为正的样本中被预测为正的比例。 F1-score：精确率和召回率的调和平均。 AUC-ROC：不受阈值影响的整体指标，0.5为随机，1为完美。AUC>0.8通常认为模型可用。

回归模型

MSE（均方误差）：对大误差敏感，因为平方放大了偏差。 RMSE：MSE开根号，与目标变量同量纲，更直观。 MAE（平均绝对误差）：对异常值不敏感。 R²：模型解释的变异比例，1为完美，0为不比均值好。

交叉验证

K折交叉验证：将数据分成K份，每次用K-1份训练、1份验证，重复K次取平均。K通常取5或10。时间序列数据不能用随机K折，要用时序分割——训练集在时间上必须在验证集之前。
